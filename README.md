# IPC Messenger

Локальный мессенджер для Linux: сервер и терминальный клиент на C++20.
Обмен через Unix-сокеты; сервер и клиенты запускаются на одной машине.

## Скачать и собрать

Для Ubuntu/Debian (CMake ≥ 3.20, компилятор с поддержкой C++20):

```sh
sudo apt-get update
sudo apt-get install git cmake g++ libncurses-dev
git clone https://github.com/Enigmater/ipc-messenger.git
cd ipc-messenger
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
```

## Запустить

В первом терминале из каталога проекта:

```sh
./build/ipcm-server
```

В остальных терминалах из того же каталога:

```sh
./build/messenger-tui
```

По умолчанию используется `/tmp/ipcm-server.sock`. Для другого пути передай
одинаковый параметр `--socket PATH` серверу и клиентам. Для кириллицы нужна
UTF-8-локаль, например `LANG=C.UTF-8`.

Сервер также можно запускать в фоновом режиме: как службу systemd или
в Docker-контейнере. Для Docker каталог с Unix-сокетом нужно подключить
общим томом, доступным клиентам, и согласовать права доступа и UID/GID.
Unit-файл systemd и Dockerfile в проект пока не включены.

## Разные пользователи Linux

Один раз создай группу и добавь нужных пользователей (замени `amor` своим логином):

```sh
sudo groupadd --system ipcm  # если группа ещё не создана
sudo usermod -aG ipcm amor
```

Заново войди в пользовательский сеанс. Сервер запускай из каталога проекта:

```sh
sudo sh scripts/run-shared-server.sh
```

Клиенты запускаются обычной командой `./build/messenger-tui`. Каталог проекта
должен быть доступен этим пользователям. Скрипт создаёт сокет с группой `ipcm`
и правами `0660`.

## Управление

- `↑` / `↓` — выбрать собеседника, `Enter` — открыть диалог или отправить текст.
- `Tab` — сменить панель, `Esc` — вернуться к списку.
- `Page Up` / `Page Down` — прокрутить историю.
- `Ctrl+Q` — выйти из клиента, `Ctrl+C` — остановить сервер.

Собеседники появляются после подключения к серверу. Для переписки выбери
имя другого пользователя; собственное имя открывает чат с собой.
Параметры клиента: `--ascii` — простые символы оформления, `--no-color` — без цветов.
История хранится в памяти клиента; сообщения offline-пользователям не доставляются.
